# SuperLearn

Учебное Android-приложение для создания собственных учебных материалов и проверки знаний. Разработано в рамках университетского проекта.

## Возможности

- Создание, переименование и удаление учебных тем.
- Редактирование теории: текст и изображения.
- Создание тестов с четырьмя вариантами ответа, прохождение и подсчёт результатов.
- Локальное хранение материалов с помощью Room.

## Стек

**Kotlin, Android Views (XML), Fragments, ViewBinding, RecyclerView, Room, Coroutines, SharedPreferences, Picasso, Espresso.**

## Реализация

Логика разделена по функциональным экранам, с отдельными репозиториями и собственными компонентами для управления состоянием и зависимостями. Есть сценарный UI-тест с использованием Espresso и Page Object.

## Статус

Учебный прототип. Загрузка вопросов из внешнего API пока не завершена.
